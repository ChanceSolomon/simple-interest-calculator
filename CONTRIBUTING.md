# Contribution Guidelines

Thank you for your interest in contributing to the Simple Interest Calculator project!

## How to Contribute

1. Fork this repository.
2. Clone your fork to your local computer.
3. Create a new branch for your changes.
4. Make your changes and test them.
5. Commit your changes with a clear commit message.
6. Push your branch to your fork.
7. Open a pull request describing your changes.

## Coding Guidelines
- Keep code simple and readable.
- Use meaningful variable names.
- Explain significant changes when necessary.
- Test your changes before submitting a pull request.

## Reporting Bugs
When reporting a bug, describe the problem, steps to reproduce it, and the expected behavior.

## Suggesting Improvements
Explain the proposed improvement and how it benefits users of the project.

## Code of Conduct
All contributors are expected to follow the guidelines in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
